# Changelog

All notable changes to this package are documented here.

## [0.2.0] - 2026-11-05

First public release.

- Package renamed to `@genzhelu/dsh-lifesci` and released under the MIT license.
- Project-specific defaults, examples and recorded fixtures removed; the plugin now ships
  generic defaults, neutral examples and synthetic offline tests.
- Documentation rewritten for general use: installation, quickstart, command/tool reference,
  portal behaviour, provenance and offline replay, security model, and optional remote execution.
